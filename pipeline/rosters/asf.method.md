# asf — ASF top-level projects (PMCs) — method
- Fetched 2026-10-05T01:29:52Z with curl: https://projects.apache.org/json/foundation/projects.json (380 DOAP projects), https://projects.apache.org/json/foundation/repositories.json (3186 repos), https://projects.apache.org/json/foundation/committees.json (216 PMCs). Raw: raw/asf/. Parser: scripts/build_foundations.py (offline, re-runnable).
- Scope: every projects.json entry whose `pmc` is not `attic` (310 DOAP projects across all 216 PMCs). The 70 entries with pmc=attic are excluded here and go to asf-attic.
- Rows A (344): one row per DOAP `repository` string. Apache git URLs (gitbox, git-wip-us, git.apache.org; `?p=` or `/repos/asf/` forms) are reduced to a repo name. If that name is a gitbox key in repositories.json, repo_url = the gitbox URL and github_slug = apache/<name>. If not, the URL is kept and no slug is given (6 rows, e.g. incubator-guacamole-*). github.com/apache/* URLs give the slug directly. svn URLs: no slug. Projects with no repository: one row with empty repo_url (62 rows; datasketches gives only non-URL "browse" entries, noted).
- Rows B (2333): repositories.json keys that no DOAP file names, assigned to a PMC by longest name prefix (key == pmc id or starts with "<pmc>-"). project = the PMC name from committees.json. Judgement call: ASF repo names carry the PMC prefix, but the PMC is not stated per repo. The note says "assigned to PMC by name prefix".
- 85 repositories.json keys match no PMC, no retired committee and no podling (infrastructure-*, apachecon-*, board-svn, ...). They are foundation infrastructure and are left out.
- github_slug apache/<repo> only for gitbox URLs (the caller's rule; ASF gitbox repos have same-name GitHub copies). svn-hosted keys (*-svn) get no slug.
- roster_status is empty: the source gives no status for active PMCs. The note gives the PMC id and marks sub-projects.
- Counts: 349 distinct project names (DOAP names plus PMC names), 2677 rows, 2615 with repo_url, 2419 with github_slug. GitHub REST calls: 0.
