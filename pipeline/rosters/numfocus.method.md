## Home page lookup (2026-10-05)
- Input: the rows of numfocus.csv with an empty repo_url (140). Output: numfocus.repos.csv (one row per such row; the original CSV is untouched).
- Method: open the page the roster links for the project, ONE step, and take the repository link that page itself gives (code host owner/repo, GitLab/Gitea/cgit/gitweb, SourceForge code, Subversion). Fetcher raw/lookup/fetch.py: one request at a time, >=2 s between any two requests, manual redirects (each hop counted as a request), 30 s timeout, at most 2 retries on network error/5xx; Firefox User-Agent. raw/lookup/pass2.py then followed <meta refresh> targets once and made one more attempt with a plain descriptive User-Agent for pages that returned 403/406. Pages: raw/numfocus/homepages/ (+ _fetch_log.jsonl). Candidates: raw/lookup/extract.py; the choice for each row was made by hand (raw/lookup/decisions.tsv) and every repo_url was checked to occur in the saved page (raw/lookup/assemble.py). GitHub REST calls: 0.
- Rule for choosing: the project's own main code repo (link labeled GitHub/Source/Code/Repository, or the repo named for the project); website-source repos ("Edit this page", *.github.io, *-web, webwml), theme credits, third-party projects and personal profiles are ignored. A link to a GitHub org / GitLab group / forge root -> repo_url = that URL, note "org only". github_slug only when repo_url is one github.com repo.
- Counts: 140 looked up; found repo 100 (96 with github_slug); org only 24; none named 10; not software 0; fetch failed 5; no link to follow 1.
- Lookup URL: sponsored rows = the 'Website' button on the NumFOCUS project page already saved in raw/numfocus/pages/ (OpenFHE has none; its first link https://www.openfhe.org/ used); affiliated rows = the homepage the roster heading links. - Judgment calls: umbrella projects whose page links an org -> org only (Stan, FEniCS, SunPy, QuantEcon, rOpenSci, Open Journals, conda-forge, OpenMBEE, SciML, Scientific Python, scverse, Fortran-lang, Clawpack, GeomScale, Gonum, igraph, Micro-Manager, PySAL, Open2C, BrainGlobe, Project Pythia, Dash -> github.com/plotly, conda -> its Website link is the GitHub org, Bioconductor -> code.bioconductor.org).
