# The full-history pilot (future work)

A pilot measured the cost and the quality of a dataset of every token in the full history of a
project. It is not part of TOM 1.0.0 and it does not change the published files. `PLAN.md`
(section "Future work: the full-history pilot") gives its state and a summary of its results.

| File | What it has |
| --- | --- |
| `REPORT.md` | The report of 2026-11-09: the design, the run on one machine (32 sample projects and the gate project), the check against TOM, the blame-tool proof, the defects of the tools and the cost model for a release with history. |

The copy of `REPORT.md` differs from the file of the work folder of the pilot in 6 lines: the
bucket name became `BUCKET_NAME`, the paths of three tool checkouts and of the read scripts on
the work host were removed, and the list of local files says that they are not here. The kit of the pilot, its results and its
logs are not here: they are in the work folder and in the bucket of the run.
