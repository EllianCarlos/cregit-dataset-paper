# Third-party sources of Token on Me (TOM)

The organization tables and some project columns of Token on Me (TOM) use data from other sources. This file gives
each source, its license or terms, and what the release must do. The authors read the terms on
2026-10-20, unless a row gives another date.

The authors read the license and the terms of each source. The authors are not lawyers. This file
is not legal advice. The release and the replication package do not publish copies of third-party
web pages. A row names the source and its web address where this file gives them.
