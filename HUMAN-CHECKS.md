# Human checks of each step

The paper says that the details and the limitations of each step are in this repository. This
file lists, for each step of TOM 1.0.0 and its revision, what is automatic, what an AI proposed,
what a human checked, and the measured result. Each number comes from the file that the last
column names. A number that no file of this repository gives is marked "not verified here".

| Step | Automatic or AI-proposed | What a human checked | Measured result | Files |
| --- | --- | --- | --- | --- |
| Selection funnel: the copy rules of the revision | Automatic: the scripts apply the fork, mirror and GitLab copy rules, and the copy check asks the host APIs for the root and head commits of each candidate and its partners. | The user decided two rule choices (2026-11-08): the copy rules beyond the fork and mirror flags apply on GitLab hosts only, and an upstream never leaves because of its own copy. The GitLab rule R2 (the same project) is a reading by hand. | 159 candidates; the copy check removed 17, decision 2 brought back 7: 149 new projects (41 pool, 108 GitLab). No project of TOM 1.0.0 leaves. | `steps/selection-funnel/README.md`, `steps/selection-funnel/data/removed.tsv`, `steps/selection-funnel/data/funnel_counts_folded.json` |
| Language rule | Automatic: tokei 14.0.0 code lines at the pinned commit. | No hand check of the values. | 8,449 projects of TOM 1.0.0 and 149 new projects pass the rule. | `steps/language-selection/tokei/RESULTS.md`, `steps/selection-funnel/data/new_projects.tsv` |
| Token files | Automatic: cregit (git blame `-C100`) and srcML. No AI made the token files. | No hand check of the rows. The gate is an automatic comparison: each machine of the new projects builds the gate project `tio__tio` of TOM 1.0.0 again with the new tool chain. | `tio__tio` is equal to its file of TOM in all 53 columns, except the pseudonym columns, which are a bijection of the TOM columns. The gate passed on the three machines of the new projects. | `steps/new-projects/README.md` (section "The gate"), `steps/release-passes/schema3-proof/` |
| Organization database 1.0.0 | A script seeded the domain map from public lists and added names, countries and parents from public registries. AI agents proposed organizations and parents for the unmatched domains from web and DNS evidence, and AI judges checked the links and the conflicts. | The user decided the open items, and checked a seeded 10% sample of the decisions of AI judge round 9. | Round 9: 1 wrong of 62 as answered (the wrong answer used the old name of a relation); 95% Clopper-Pearson interval 0.04% to 8.66%. The user saw the AI verdict, so the rate is a lower bound (anchoring). | `steps/organizations/study/s8-companies/error_model.py` (`ai_round_check`), `steps/error-model/results/tables.md` (parameters table), `steps/organizations/study/s8-companies/ERROR_MODEL.md` |
| Domain links (`firm_based_on_domain`) | The links come from the domain map of the database. | A domain audit on TOM: a systematic sample with a probability proportional to the tokens of each domain. | 514 decided answers (437 right, 77 wrong). The error is 2.921% of the tokens of TOM (95% interval 1.465% to 4.904%); the paper gives 2.9%. The answers are not public (they name domains). | `LIMITATIONS.md` (section TOM 1.0.0), `steps/release-passes/pass-5-revision/docs/docs/ERROR.md` |
| Namespace owners (`firm_based_on_namespace`) | The owner of each namespace comes from the database (account profiles, rosters, verified domains, name matches). | A namespace audit on TOM. | 650 decided answers, 0 wrong: 0.0% of the projects (95% interval 0.0% to 6.00%). The earlier audit on the source root of the release passes had 766 decided answers, 0 wrong (95% interval 0.0% to 5.57% of the projects). | `steps/release-passes/pass-5-revision/docs/docs/ERROR.md`, `steps/error-model/results/tables.md` (`column_audit_state`, `column_audit_estimate`) |
| License values of the revision | Automatic: ScanCode 32.5.0, the SPDX template diff and fixed rules (ctp `feat/license-scan` `0f9b8ad`). No AI made the license values. | The user judged a seeded sample of 100 of the 1,455 new values (stratified by confidence and evidence kind) on a local page. | 0 wrong of 100 (95% Wilson interval 0.0% to 3.7%); high confidence 0 of 68, medium 0 of 32; no corrections. The 100th answer came from the report of the user, because the page refused to save it. | `steps/license-pass/README.md`, `steps/license-pass/work/audit/answers.tsv`, `steps/license-pass/work/audit/AUDIT_OK` |

Notes:

- The domain and namespace audits on TOM have their numbers in `docs/ERROR.md` of the release.
  This repository has the staged copy of that file (`steps/release-passes/pass-5-revision/docs/docs/ERROR.md`,
  the same bytes as the staged file of pass 4). The design of the column audits is in
  `steps/organizations/study/s8-companies/ERROR_MODEL.md`.
- The pseudonyms are automatic (`pseudonymize.py`); this list has no hand check of them.
